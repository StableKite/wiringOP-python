# `wiringPi/mcp3422.h`

Python-модуль: `wiringop.wiring_pi.mcp3422`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Функции

- `mcp3422Setup` → `mcp3422_setup(pin_base, i2c_address, sample_rate, gain)`; C return `int`; адаптация `direct`.

## Макросы

- `MCP3422_SR_240` → `MCP3422_SR_240`: экспортируется; `value`; определение `0`.
- `MCP3422_SR_60` → `MCP3422_SR_60`: экспортируется; `value`; определение `1`.
- `MCP3422_SR_15` → `MCP3422_SR_15`: экспортируется; `value`; определение `2`.
- `MCP3422_SR_3_75` → `MCP3422_SR_3_75`: экспортируется; `value`; определение `3`.
- `MCP3422_GAIN_1` → `MCP3422_GAIN_1`: экспортируется; `value`; определение `0`.
- `MCP3422_GAIN_2` → `MCP3422_GAIN_2`: экспортируется; `value`; определение `1`.
