# `wiringPi/w25q64.h`

Python-модуль: `wiringop.wiring_pi.w25q64`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Функции

- `W25Q64_begin` → `w25q64_begin(cs)`; C return `void`; адаптация `direct`.
- `W25Q64_readStatusReg1` → `w25q64_read_status_reg1()`; C return `uint8_t`; адаптация `direct`.
- `W25Q64_readStatusReg2` → `w25q64_read_status_reg2()`; C return `uint8_t`; адаптация `direct`.
- `W25Q64_readManufacturer` → `w25q64_read_manufacturer(d)`; C return `void`; адаптация `w25_manufacturer`.
- `W25Q64_readUniqieID` → `w25q64_read_unique_id(d)`; C return `void`; адаптация `w25_unique_id`.
- `W25Q64_IsBusy` → `w25q64_is_busy()`; C return `bool`; адаптация `direct`.
- `W25Q64_powerDown` → `w25q64_power_down()`; C return `void`; адаптация `direct`.
- `W25Q64_WriteEnable` → `w25q64_write_enable()`; C return `void`; адаптация `direct`.
- `W25Q64_WriteDisable` → `w25q64_write_disable()`; C return `void`; адаптация `direct`.
- `W25Q64_read` → `w25q64_read(addr, buf, n)`; C return `uint16_t`; адаптация `w25_read`.
- `W25Q64_fastread` → `w25q64_fast_read(addr, buf, n)`; C return `uint16_t`; адаптация `w25_read`.
- `W25Q64_eraseSector` → `w25q64_erase_sector(sect_no, flgwait)`; C return `bool`; адаптация `direct`.
- `W25Q64_erase64Block` → `w25q64_erase64_block(blk_no, flgwait)`; C return `bool`; адаптация `direct`.
- `W25Q64_erase32Block` → `w25q64_erase32_block(blk_no, flgwait)`; C return `bool`; адаптация `direct`.
- `W25Q64_eraseAll` → `w25q64_erase_all(flgwait)`; C return `bool`; адаптация `direct`.
- `W25Q64_pageWrite` → `w25q64_page_write(sect_no, inaddr, data, n)`; C return `uint16_t`; адаптация `w25_page_write`.
