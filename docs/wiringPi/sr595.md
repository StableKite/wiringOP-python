# `wiringPi/sr595.h`

Python-модуль: `wiringop.wiring_pi.sr595`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Функции

- `sr595Setup` → `sr595_setup(pin_base, num_pins, data_pin, clock_pin, latch_pin)`; C return `int`; адаптация `direct`.
