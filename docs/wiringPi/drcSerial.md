# `wiringPi/drcSerial.h`

Python-модуль: `wiringop.wiring_pi.drc_serial`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Функции

- `drcSetupSerial` → `drc_setup_serial(pin_base, num_pins, device, baud)`; C return `int`; адаптация `direct`.
