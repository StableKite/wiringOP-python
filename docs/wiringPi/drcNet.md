# `wiringPi/drcNet.h`

Python-модуль: `wiringop.wiring_pi.drc_net`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Функции

- `drcSetupNet` → `drc_setup_net(pin_base, num_pins, ip_address, port, password)`; C return `int`; адаптация `direct`.
