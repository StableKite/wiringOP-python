# `wiringPi/wpiExtensions.h`

Python-модуль: `wiringop.wiring_pi.wpi_extensions`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Функции

- `loadWPiExtension` → `load_wpi_extension(prog_name, extension_data, verbose)`; C return `int`; адаптация `mutable_c_string`.
