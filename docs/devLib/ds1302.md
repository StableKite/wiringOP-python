# `devLib/ds1302.h`

Python-модуль: `wiringop.dev_lib.ds1302`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Функции

- `ds1302rtcRead` → `ds1302rtc_read(reg)`; C return `unsigned int`; адаптация `direct`.
- `ds1302rtcWrite` → `ds1302rtc_write(reg, data)`; C return `void`; адаптация `direct`.
- `ds1302ramRead` → `ds1302ram_read(addr)`; C return `unsigned int`; адаптация `direct`.
- `ds1302ramWrite` → `ds1302ram_write(addr, data)`; C return `void`; адаптация `direct`.
- `ds1302clockRead` → `ds1302_clock_read(clock_data)`; C return `void`; адаптация `ds1302_clock_read`.
- `ds1302clockWrite` → `ds1302_clock_write(clock_data)`; C return `void`; адаптация `ds1302_clock_write`.
- `ds1302trickleCharge` → `ds1302trickle_charge(diodes, resistors)`; C return `void`; адаптация `direct`.
- `ds1302setup` → `ds1302setup(clock_pin, data_pin, cs_pin)`; C return `void`; адаптация `direct`.
