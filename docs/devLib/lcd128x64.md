# `devLib/lcd128x64.h`

Python-модуль: `wiringop.dev_lib.lcd128x64`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Функции

- `lcd128x64setOrigin` → `lcd128x64set_origin(x, y)`; C return `void`; адаптация `direct`.
- `lcd128x64setOrientation` → `lcd128x64set_orientation(orientation)`; C return `void`; адаптация `direct`.
- `lcd128x64orientCoordinates` → `lcd128x64orient_coordinates(x, y)`; C return `void`; адаптация `output_pointers`.
- `lcd128x64getScreenSize` → `lcd128x64_get_screen_size(x, y)`; C return `void`; адаптация `lcd_screen_size`.
- `lcd128x64point` → `lcd128x64point(x, y, colour)`; C return `void`; адаптация `direct`.
- `lcd128x64line` → `lcd128x64line(x0, y0, x1, y1, colour)`; C return `void`; адаптация `direct`.
- `lcd128x64lineTo` → `lcd128x64line_to(x, y, colour)`; C return `void`; адаптация `direct`.
- `lcd128x64rectangle` → `lcd128x64rectangle(x1, y1, x2, y2, colour, filled)`; C return `void`; адаптация `direct`.
- `lcd128x64circle` → `lcd128x64circle(x, y, r, colour, filled)`; C return `void`; адаптация `direct`.
- `lcd128x64ellipse` → `lcd128x64ellipse(cx, cy, x_radius, y_radius, colour, filled)`; C return `void`; адаптация `direct`.
- `lcd128x64putchar` → `lcd128x64putchar(x, y, c, bg_col, fg_col)`; C return `void`; адаптация `direct`.
- `lcd128x64puts` → `lcd128x64puts(x, y, str, bg_col, fg_col)`; C return `void`; адаптация `direct`.
- `lcd128x64update` → `lcd128x64update()`; C return `void`; адаптация `direct`.
- `lcd128x64clear` → `lcd128x64clear(colour)`; C return `void`; адаптация `direct`.
- `lcd128x64setup` → `lcd128x64setup()`; C return `int`; адаптация `direct`.
