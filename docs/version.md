# `version.h`

Python-модуль: `wiringop.version`.

Модуль зеркально покрывает публичный API заголовка wiringOP. Имена Python приведены к Python-стилю; рядом сохраняются C-имена для однозначного сопоставления.

## Макросы

- `VERSION` → `VERSION`: экспортируется; `value`; определение `"2.46"`.
- `VERSION_MAJOR` → `VERSION_MAJOR`: экспортируется; `value`; определение `2`.
- `VERSION_MINOR` → `VERSION_MINOR`: экспортируется; `value`; определение `46`.
